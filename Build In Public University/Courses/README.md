# Courses

Open, prospective course materials for Build In Public University.

## Available course artifacts

- [Responsible AI: Cats vs Cards](Responsible%20AI%20-%20Cats%20vs%20Cards/README.md) — a prospective course on testing, containing, and correcting conversational AI systems.

Course directories are designed to be forked, adapted, and extended. If you want a new course or a deeper module, open an issue with the intended audience, learning goal, and practical artifact you want participants to leave with.
