CONCEPT 06 · CASE STUDY

Dashboards as evidence

What can be checked without trusting the narrator?

A dashboard is useful when it exposes the measurement definition, time window, source, and limitations. A number without a denominator, timestamp, or query path is a prop.

TRY THIS

Make the mechanism smaller.

Choose one public metric. Write what it counts, what it excludes, when it was measured, and what independent check could disagree with it.

Falsifier to carry forward: If the dashboard is unavailable, stale, or selectively defined, which part of the thesis becomes untestable?
